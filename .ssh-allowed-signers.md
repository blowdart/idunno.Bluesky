# SSH Allowed Signers

[`.ssh-allowed-signers`](.ssh-allowed-signers) contains the SSH public keys trusted for signing **commits and tags** in this repository.

## Format

```text
principal key-type public-key-data comment
```

## Current Trusted Keys

- **<github.com@idunno.org>** - 1password backed signing key

## Verification

Git will not read this file until you point it at it. The setting lives in `.git/config`, which is **per clone**, so this has to be
run once on every machine and every fresh clone. Git deliberately provides no way for a repository to configure itself, because a
repository which could set values such as `core.hooksPath` would be able to run code on `git clone`.

```bash
# Configure Git to use this file. Run this once per clone, from the root of the repository.
git config gpg.ssh.allowedSignersFile .ssh-allowed-signers
```

The path is resolved relative to the root of the working tree rather than the current directory, so the command above works from
anywhere in the repository afterwards.

Once it is configured:

```bash
# Verify a single commit
git verify-commit HEAD

# Show the signature alongside the log
git log --show-signature -1

# Verify a tag
git verify-tag v6.0.0
```

A verified commit or tag reports:

```text
Good "git" signature for github.com@idunno.org with ED25519 key SHA256:mLCP3Lii5481QHysZeyYaCKA/enf3M6DQm0ZGkhHCGU
```

`git log` can also report the status of each commit compactly through the `%G?` format specifier, where `G` is a good signature
from a trusted key, `U` is a good signature from a key which is *not* listed in the allowed signers file, and `N` is no signature
at all:

```bash
git log --format='%h %G? %GS' -5
```

Note that `U` rather than a failure is what you will see when this file is not configured, or when it does not list the key which
made the signature, so a silent `U` is worth checking rather than ignoring.

Commits created by GitHub itself, such as those made when a pull request is squashed and merged, are signed with GitHub's own GPG
key rather than an SSH key. Those are verified by GitHub on the web, and will report `N` locally unless `gpg` is installed.
