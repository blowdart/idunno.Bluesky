# idunno.AtProto.AspNet.Spaces

## About

ASP.NET Core helpers for hosting AT Protocol Spaces endpoints.

## Key Features

* Provides a framework-neutral managed-space access handler with an ASP.NET Core endpoint helper.
* Trimming is supported for applications targeting .NET 9.0 or later.

## Documentation

See the [AT Protocol Spaces documentation](https://bluesky.idunno.dev/docs/spaces.html) for setup and managing-app endpoint configuration.
