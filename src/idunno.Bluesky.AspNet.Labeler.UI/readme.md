# idunno.Bluesky.AspNet.Labeler.UI

## About

Optional Xenon Razor Pages administration UI for a standalone AT Protocol labeler.

## Key Features

* Bluesky sign-in with shared labeler team authorization
* Report, case and appeal review
* Manual labeling and account or record inspection
* Policy publication, team administration and audit history
* Guided maintenance and retirement workflows
* Light, dark and system themes

## Version History

A full [version history](https://github.com/blowdart/idunno.Bluesky/blob/main/CHANGELOG.md) can be found on the project's

## How to Use

Register labeler administration and Bluesky authentication, then add this package's
pages and map Razor Pages after authentication and authorization middleware.

## Related Packages

* [idunno.Bluesky.AspNet.Labeler](https://www.nuget.org/packages/idunno.Bluesky.AspNet.Labeler) provides the hosting and moderation backend.
* [idunno.Bluesky.AspNet.Authentication](https://www.nuget.org/packages/idunno.Bluesky.AspNet.Authentication) provides Bluesky authentication for ASP.NET Core.
