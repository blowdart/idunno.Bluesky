# idunno.Bluesky.AspNet.Labeler.UI

Optional Xenon Razor Pages administration UI for a standalone AT Protocol labeler.

Register labeler administration and Bluesky authentication, then add this package's
pages and map Razor Pages after authentication and authorization middleware. See the
[Xenon UI guide](https://bluesky.idunno.dev/docs/labeller/ui.html) for the complete
configuration and security requirements.
