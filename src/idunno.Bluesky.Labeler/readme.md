# idunno.Bluesky.Labeler

Host-neutral persistence contracts for signed AT Protocol labels. Register exactly one of the SQLite,
PostgreSQL or MySQL provider packages. Signing, authorization, protocol hosting and private-key custody
are separate concerns. Start with the [labeller overview](https://bluesky.idunno.dev/docs/labeller/overview.html)
for how these pieces fit together and the lifecycle of a labeller.
